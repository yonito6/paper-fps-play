# Desk Town: map assets (MAP agent)

A cardboard and paper toy town on a giant desk: a 3-lane team deathmatch map, mirrored across x = 0 (blue = -x, red = +x).
Everything is generated by script, so it can be rebuilt any time and re-imported in Unity:
`python render/paper/map/make_textures.py` -> `blender -b --factory-startup -P render/paper/map/build_map.py` ->
`blender -b --factory-startup -P render/paper/map/bake_map.py -- 4096 128` -> `... preview_map.py -- game|gamert|raw`.

## Units and axes
Metres, **+Y up** (glTF), player 1.8 m tall (eye 1.65 m, radius 0.4). Game x = Blender x, game y = Blender z, game z = -Blender y.
In game space blue spawns at x = -42, red at x = +42; the "north" side of the map (high lane, clock tower, viaduct) is game **-z**.

## Files
| File | What |
|---|---|
| `desktown.glb` | Static town merged **per material**: `desktown_kraft`, `desktown_paper`, `desktown_edge`, `desktown_mat`, `desktown_print` (5 draw calls), plus one node per tearable panel `T_<id>` (origin = panel centre; glTF `extras.tear` = id, w, h, t, creases, front/back). Attributes: POSITION, NORMAL, TANGENT, TEXCOORD_0 (material UV, world-projected, repeat), **TEXCOORD_1 (lightmap UV)**, COLOR_0 (per-panel tint: multiply). Textures are embedded (same files as `tex/`). |
| `tex/` | `kraft_diff/nor.jpg` (2048, tile 2 m), `paper_diff/nor.jpg` (1024, tile 2 m), `edge_diff.jpg` (corrugated cut edge), `mat_diff.jpg` (cutting mat, tile 10 m), `atlas_diff.png` (print atlas, no wrap). Normal maps OpenGL convention. Wrap = Repeat for all except the atlas (ClampToEdge is fine). |
| `lm.png` (4096) / `lm_2k.png` | Lightmap for use **with the live sun**: sky + static lamps (direct + bounce) + the sun's bounce only. |
| `lm_full.png` (4096) / `lm_full_2k.png` | Fully baked lightmap incl. the sun's direct light and shadows (Performance tier, or statics without a live shadow map). |
| `../../../data/paper/map_desktown.json` | Gameplay data: colliders, spawns, tearable panels, plane windows, nav lane hints + camps, static lamps, sun / sky / fog. |
| `../../../render/paper/map/bake_meta.json` + `look.json` | Lightmap scales + the light numbers (sun direction / colour, sky colours, fog, exposure). |

## Lightmap decode (same convention as Sector Nine's LOOK pipeline, docs/agents/LOOK.md)
PNG is Non-Color (load with `LinearEncoding` / `NoColorSpace`), value = `sqrt(light / scale)`; `light = texel^2 * scale`
(scale in `bake_meta.json`). Light is linear diffuse light for a white surface: `final = albedo * COLOR_0 * light` (+ the live sun
direct term when using `lm.png`). three r147: GLTFLoader puts TEXCOORD_1 in the `uv2` attribute = the lightMap channel; patch the
shader (like gfxlook's `|lk1` key) to square + scale the sample, or pre-decode into a float/half texture at load.

## Loading (three.js r147)
```js
const gltf = await new GLTFLoader().loadAsync('assets/paper/map/desktown.glb');
gltf.scene.traverse(o => { if (o.isMesh) { o.material.vertexColors = true; o.material.flatShading = false; /* normals are already split per fold */
  o.material.lightMap = lmTex; o.material.lightMapIntensity = 1; } });
// tearable panels: gltf.scene.getObjectByName('T_blue_gal_w0').userData.tear (JSON string) and data/paper/map_desktown.json "tearable"
```
Colliders: axis-aligned boxes in `colliders` as `[minX, minY, minZ, maxX, maxY, maxZ, kind, note]`. Kinds: `solid`, `walk` (top is a floor:
stairs, decks, raised floors), `rail` (thin wooden rails, 1.08 m), `tear` (the panel's box while intact; remove/shape it when torn), `floor`.

## Shot marks / decals on every surface
Every mesh has a proper material UV (world-projected, metres / tile) plus a unique lightmap UV and tangents, so runtime hole / dent
decals (LEAD) can project onto any surface; use the face normal from the hit and the kraft/paper material under it.
